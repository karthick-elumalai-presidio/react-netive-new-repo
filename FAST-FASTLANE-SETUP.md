## 🔐 iOS Automatic Signing (New)

### **What Changed:**

**Before (Match):**
- Required Match repository
- Required SSH keys or HTTPS tokens
- Complex setup
- ❌ Was failing

**After (Automatic Signing):**
- Uses Xcode automatic signing
- Only needs APPLE_TEAM_ID
- Simple credential-based upload
- ✅ Works with your existing credentials

### **How It Works:**

1. **Building IPA:**
   - Uses `APPLE_TEAM_ID` for automatic code signing
   - Xcode manages certificates automatically
   - No Match repository needed

2. **Uploading to TestFlight:**
   - Uses `APPLE_ID` + `APPLE_APP_SPECIFIC_PASSWORD`
   - OR uses `APP_STORE_CONNECT_API_KEY_JSON`
   - Simple authentication

## 🐛 Troubleshooting

### **Error: "Android native project not found"**

**Cause**: You haven't committed the android/ folder yet

**Fix**:
```bash
bun run prebuild --platform android --clean
git add android/
git commit -m "chore: add android native project"
git push
```

---

### **Error: "iOS native project not found"**

**Cause**: You haven't committed the ios/ folder yet

**Fix**:
```bash
bun run prebuild --platform ios --clean
git add ios/
git commit -m "chore: add ios native project"
git push
```

---

### **iOS Build: "Signing certificates not available"**

**Cause**: Automatic signing can't find valid certificates in Apple Developer account

**Solutions**:

1. **Ensure you have valid Apple Developer account**
2. **Check bundle identifier matches** in Xcode
3. **Manually create certificates** in Apple Developer Portal
4. **Or use Match** (more complex, but more reliable for CI)

---

### **iOS Build: Still using Xcode 16.4**

**Note**: This is expected on macos-15. The workflow will select appropriate Xcode version automatically.
